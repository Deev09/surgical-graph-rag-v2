\section{The scope discipline in full}
\label{ssec:scopes}

Every numeric claim in the main paper carries a scope. The scope is not a
narrative convention: it is a column of the results registry that accompanies
the submission (283 rows, each carrying exactly one scope), and the
claim-to-registry audit of \cref{ssec:audit} machine-checks that no claim
exceeds what its scope may assert. \Cref{tab:scopes} lists the seven scopes,
what a row within each may claim, and how many registry rows carry each. The
row counts are computed from the registry itself, not transcribed.

    \texttt{oracle\_free\_\allowbreak component\_\allowbreak eval} & the prediction path is

Answer production and grading are separate functions throughout: no layer
that produces an answer may read an expected value, and a syntax-tree test
fails the build if a deployable answer function so much as binds a
key-shaped name.
